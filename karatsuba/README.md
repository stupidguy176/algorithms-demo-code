

## 🌍 Websites with problems related to Karatsuba

### 1. **GeeksforGeeks**

* Has an article **Karatsuba Algorithm for Fast Multiplication using Divide and Conquer** with theory + sample code.
* Also has practice problems (e.g., multiply big integers, multiply binary strings).
  👉 [GeeksforGeeks Karatsuba](https://www.geeksforgeeks.org/karatsuba-algorithm-for-fast-multiplication-using-divide-and-conquer-algorithm)

---

### 2. **Codeforces**

* Some problems about **polynomial multiplication** or **big integer multiplication** can be solved using Karatsuba or FFT.
* The blog section also contains explanations and code for Karatsuba to use in contests.
  👉 [Codeforces Blog on Karatsuba](https://codeforces.com/blog/entry/74209)

---

### 3. **SPOJ (Sphere Online Judge)**

* Has problems like “Multiply Large Numbers,” e.g., **MUL - Fast Multiplication**.
* Inputs often have 10⁴–10⁵ digits → you must use a fast algorithm (Karatsuba, FFT, or NTT).
  👉 [SPOJ MUL problem](https://www.spoj.com/problems/MUL/)

---

### 4. **UVa Online Judge**

* Classic problem **Multiplying Big Numbers** (UVa 10106).
* You can solve with schoolbook multiplication, but optimizing with Karatsuba is a good exercise.
  👉 [UVa 10106](https://onlinejudge.org/index.php?option=onlinejudge&page=show_problem&problem=1047)

---

### 5. **Kattis**

* Contains problems on **Big Integer Multiplication / Polynomial Multiplication**.
* Example: “polymul” (Polynomial Multiplication). Karatsuba or FFT are effective solutions.
  👉 [Kattis polymul](https://open.kattis.com/problems/polymul)

---

### 6. **Project Euler**

* Some problems involve **large number arithmetic** → Karatsuba can be used to speed up solutions.
* Not required directly, but useful for practice.
  👉 [Project Euler](https://projecteuler.net/)

---

✅ **Summary**:

* **Direct problems**: GeeksforGeeks, SPOJ (MUL), UVa (10106).
* **Indirect (suitable for Karatsuba)**: Codeforces (polynomial problems), AtCoder (advanced math contests), Kattis.
